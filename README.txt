БИБЛИОТЕКА ХУТБ — файлы для публикации

Что внутри:
 index.html              — само приложение (все хутбы внутри)
 manifest.webmanifest    — описание приложения (название, цвета, иконки)
 sw.js                   — работа без интернета
 icon-*.png, apple-touch-icon.png — иконки (полумесяц и буква M)

ШАГ 1. Публикация на GitHub Pages
 1. Зайдите на github.com, нажмите «+» → New repository.
 2. Название лучше такое: ВАШЛОГИН.github.io (тогда адрес будет https://ВАШЛОГИН.github.io/).
    Поставьте «Public». Нажмите Create repository.
 3. Нажмите «uploading an existing file» и перетащите ВСЕ файлы из этой папки
    (включая файл .nojekyll, если он виден). Нажмите Commit changes.
 4. Settings → Pages → Source: «Deploy from a branch», Branch: main, папка / (root) → Save.
 5. Через 1–2 минуты сайт откроется по адресу https://ВАШЛОГИН.github.io/

ШАГ 2. Проверка
 Откройте адрес в Chrome на телефоне. Должно предложить «Установить приложение».

ШАГ 3. APK
 1. Откройте pwabuilder.com, вставьте адрес сайта, нажмите Start.
 2. Когда проверка завершится, нажмите Package for stores → Android.
 3. Заполните Package ID (например, io.github.ВАШЛОГИН.khutby), название «Библиотека хутб».
 4. Нажмите Generate и скачайте архив. Внутри будет APK (и файл ключа — сохраните его!).
 5. Отправьте APK на телефон и установите (разрешите установку из неизвестных источников).

Обновление хутб: заменяйте файл index.html в репозитории, а в sw.js меняйте номер
версии (const V="khutby-v1" → "khutby-v2"), чтобы у людей обновилось.
